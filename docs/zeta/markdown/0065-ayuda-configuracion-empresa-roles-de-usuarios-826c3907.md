# Roles de Usuarios

En ZetaSoftware, la asignación de **roles de usuario** es un proceso crucial que permite a cada empresa personalizar no sólo qué usuarios podrán acceder y trabajar en su entorno, sino también el rol que desempeñarán, el cual se define de acuerdo al permiso asignado.

El rol con su correspondiente permiso, le dirá al sistema a qué opciones y funcionalidades de ZetaSoftware podrá ingresar y utilizar, y a cuáles no. Por ejemplo, un usuario puede tener un rol dentro de la empresa A como Administrativo, y otro rol en la empresa B como Contador.

### Asignar Rol a un Usuario

-   **Rol Usuario:** Guarda el nombre del Usuario de ZetaSoftware vinculado a ese rol específico. Se puede personalizar para dar mayor contexto, por ejemplo “Juan Pérez (Contador)”.
-   **Email:** Email del Usuario ZetaSoftware al cual se le va a asignar un rol dentro de la empresa. Se verificará que exista el email.

### Permisos

El Tipo de permiso puede ser:

-   **Administrador:** Tiene total acceso sin restricciones de ningún tipo a todas las funcionalidades de ZetaSoftware. El rol con código 1 siempre será de tipo Administrador. Puede dar de baja otros usuarios y crear nuevos roles.
-   **Supervisor:** A diferencia del Administrador, no podrá AGREGAR nuevos roles en la grilla ni desactivar usuarios con roles asignados.
-   **Operador:** Los accesos estarán restringidos según el Permiso de Acceso que se le asigne, además no podrá entrar a la grilla de Roles de Usuarios.

### Otras restricciones

-   **Caducidad:** Fecha hasta la cual el usuario tendrá acceso a la empresa.
-   **Horario:** Rango de horas entre las cuales el usuario tendrá acceso a la empresa.
-   **Chat con Soporte:** Indica si el usuario tiene acceso al Soporte Online dentro de la aplicación.

### Otros datos

-   **Local:** Si se le asigna un local comercial o sucursal al usuario, no le permitirá seleccionar otro local.
-   **Caja:** Si se le asigna una caja al usuario, no le permitirá seleccionar otra caja.
-   **Centro de Costos:** Se sugerirá en todos los comprobantes o asientos que registre el usuario.
-   **Vendedor:** Será sugerido en el módulo de Oportunidades de Venta y en las Facturas de Venta.
-   **Notas:** Para registrar cualquier tipo de comentario.

### Restricciones de Visualización y Acceso

-   Solo los usuarios de Tipo ADMINISTRADOR o SUPERVISOR podrán entrar a la grilla de Roles de Usuarios.
-   El usuario con el Código 1 siempre será ADMINISTRADOR y no podrá ser eliminado.
-   Solo el usuario con el Código 1 podrá cambiar las casillas de correo de cualquier otro usuario.
-   Solo los usuarios de Tipo ADMINISTRADOR podrán agregar nuevos roles o cambiar cualquiera de los ya existentes.
-   Los usuarios ADMINISTRADOR o SUPERVISOR no podrán tener fecha de Caducidad u horario restringido.
-   Los usuarios SUPERVISOR no verán en la grilla a los usuarios ADMINISTRADORES.
-   Los usuarios OPERADOR no tendrán acceso a la grilla de Roles de Usuarios.

### Acciones de la grilla

-   **Ver:** Permite visualizar los datos del rol.
-   **Modificar:** Permite editar y modificar los datos del rol.
-   **Eliminar:** El usuario a eliminar no debe haber registrado ningún comprobante.
-   **Historial:** Permite ver el historial de entradas y salidas al sistema.
-   **Comprobantes Vinculados:** Visualiza todos los comprobantes ingresados o modificados por el usuario.
-   **Borrar Parámetros Informes:** Borra los parámetros guardados de cada reporte emitido.
-   **Cambiar Email:** Solo lo podrá hacer el usuario con código 1.
-   **Inactivar Usuario:** Solo podrán inactivarse usuarios por administradores.
