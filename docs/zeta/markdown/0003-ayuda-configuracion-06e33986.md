# Configuración

La **Configuración** en ZetaSoftware para los módulos de Gestión PyME, Facturación Profesional y Contabilidad, te permite personalizar el sistema acorde a las necesidades de tu negocio.

Esta funcionalidad ofrece múltiples opciones que te ayudan a definir aspectos esenciales, como clientes, proveedores, productos e impuestos, además de políticas de precios y cuentas contables, entre otros.
