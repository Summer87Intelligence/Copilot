# Estados de Oportunidades

Los **Estados de las Oportunidades** representan el progreso de una oportunidad de venta desde su identificación hasta su finalización. Estos estados son personalizables, permitiendo a cada empresa adaptar el flujo de trabajo de sus ventas a su propio proceso.

### Datos a configurar

-   **Código:** Número identificador único del estado. Los códigos de los Estados pueden variar desde 1 a 99. Algunos códigos ya vienen predeterminados por el sistema y no pueden ser cambiados: código 1 para ‘Sin iniciar’, código 2 para ‘Iniciada’, código 98 para ‘Perdida’ y código 99 para ‘Ganada’.
-   **Nombre:** Etiqueta descriptiva del estado que proporciona un contexto fácil de entender para los usuarios.
-   **% Probabilidad:** Estimación de la probabilidad de éxito de la oportunidad en ese estado en particular. Este porcentaje es útil para proyectar ventas futuras y para analizar el rendimiento de ventas.

### Ejemplos de estados intermedios

Considerando códigos intermedios, es posible crear estados que reflejen con precisión el flujo de trabajo de ventas de una empresa:

-   **Código 3 – “Presentación de la propuesta” – 50%:** Este estado podría utilizarse cuando se ha presentado una propuesta de venta al cliente.
-   **Código 5 – “Negociación” – 70%:** Este estado sería útil cuando la propuesta está siendo negociada con el cliente.
-   **Código 7 – “Contrato en revisión” – 90%:** Este estado podría aplicarse cuando el contrato de venta está siendo revisado antes de la finalización.

Estos estados intermedios ayudan a las empresas a monitorizar y gestionar el progreso de cada oportunidad de venta, asegurando que ninguna oportunidad se pierda o se quede en el olvido.
