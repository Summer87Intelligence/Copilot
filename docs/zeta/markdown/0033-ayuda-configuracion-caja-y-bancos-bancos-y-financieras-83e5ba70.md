# Bancos y Financieras

En ZetaSoftware, ofrecemos un medio sencillo y efectivo para mantener un registro detallado de los **Bancos y Financieras** con los que tu empresa tiene relaciones comerciales. Este recurso es fundamental para una gestión efectiva de tus cuentas bancarias, cheques, vouchers y diversos informes financieros.

La tabla de Bancos y Financieras se compone de varios campos:

-   **Código:** Un número que identifica de manera única cada Banco o Financiera dentro del sistema.
-   **Nombre:** El nombre oficial del Banco o la Financiera. Por ejemplo, “Banco Santander” o “Visa”.
-   **Abreviación:** Una versión corta del nombre de la entidad, útil para visualizaciones simplificadas.
-   **Tipo:** Indica si la entidad es un “Banco” o una “Financiera”. Por ejemplo, un banco sería “BBVA”, mientras que una financiera podría ser “MasterCard”.
-   **Notas:** Espacio libre para información adicional sobre la entidad, como detalles sobre términos de servicio o contactos clave.

La correcta configuración de los Bancos y Financieras es un paso crucial para luego definir las **Cuentas Bancarias** de tu empresa. Cada cuenta bancaria que configures deberá tener un banco asignado.

Además, la definición de Bancos y Financieras se utiliza para indicar de dónde provienen los cheques y vouchers que recibe tu empresa, lo que permite un seguimiento más eficiente de las transacciones. También es un filtro útil para personalizar y simplificar la visualización de los diferentes informes financieros.
