# Objetivo
Mejorar experiencia visual e interaccion sin comprometer rendimiento ni accesibilidad.

# Activar skills
- frontend-ui-ux
- dev-performance

# Reglas
- Priorizar claridad de jerarquia y llamadas a la accion.
- Mantener accesibilidad y consistencia visual.
- Medir impacto en performance del frontend.

# Flujo
1. Auditar flujos y pantallas criticas.
2. Ajustar estructura visual y microinteracciones.
3. Optimizar componentes y carga de recursos.
4. Validar accesibilidad y tiempos de respuesta.
5. Consolidar mejoras con criterios de calidad.

# Output
- Lista priorizada de mejoras UI/UX.
- Ajustes de performance recomendados.
- Checklist de validacion visual y tecnica.
