# SaaS Definition of Done

Antes de considerar lista una feature SaaS:

## Seguridad
- Auth validada
- Autorización validada
- Tenant isolation validado
- Inputs validados
- Secrets fuera del cliente

## Backend
- APIs con validación
- Errores manejados
- Idempotencia donde aplique
- Logs mínimos

## Database
- Índices revisados
- Queries críticas revisadas
- RLS/policies revisadas si aplica

## UX
- Estados loading/error/empty
- Mobile o responsive según necesidad
- Copy claro

## Cierre
- Self-audit hecho
- PROJECT_CONTEXT.md actualizado
- TASKS.md actualizado
