# Landing Definition of Done

Antes de considerar lista una landing:

## Conversión
- Hero comunica propuesta de valor en menos de 5 segundos
- CTA principal visible en desktop y mobile
- CTA secundario disponible si aplica
- Formulario/contacto funcional
- WhatsApp visible si el mercado lo usa

## Confianza
- Dirección/contacto real si es negocio físico
- Imágenes reales o placeholders de alta calidad
- Testimonios o prueba social si existen
- Footer completo

## Técnica
- Metadata OG configurada
- Mobile revisado
- Contraste aceptable
- Sin placeholders obvios en producción
- Performance razonable

- PROJECT_CONTEXT.md actualizado
- TASKS.md actualizado
- Pendientes documentados
