# AI Copilot Definition of Done

Antes de considerar listo un copilot/agente:

## Utilidad
- Objetivo del agente definido
- Usuario objetivo definido
- Output accionable
- Límites claros

## Contexto
- Fuentes de datos definidas
- Memoria/persistencia definida
- Ventana de contexto controlada
- No inventa datos críticos

## Operación
- Logs de ejecución
- Fallback si falla IA
- Latencia razonable
- Costos considerados

## Seguridad
- No filtra datos sensibles
- Respeta tenant/user scope
- No ejecuta acciones peligrosas sin validación

## Cierre
- Prompt base documentado
- PROJECT_CONTEXT.md actualizado
- TASKS.md actualizado
