# Objetivo
Construir y entregar cambios listos para produccion con foco en robustez tecnica y riesgo controlado.

# Activar skills
- architecture-system-design
- database-postgresql
- backend-realtime
- security-web

# Reglas
- Priorizar cambios pequenos, seguros y reversibles.
- Asegurar validacion de inputs y controles de seguridad.
- Medir impacto en performance antes de cerrar.

# Flujo
1. Definir alcance tecnico y contratos del cambio.
2. Modelar arquitectura y datos segun requisitos.
3. Implementar con controles de seguridad web.
4. Validar rendimiento y comportamiento realtime.
5. Entregar checklist de despliegue y riesgos.

# Output
- Plan tecnico de implementacion.
- Checklist de seguridad/performance.
- Riesgos y mitigaciones para deploy.
