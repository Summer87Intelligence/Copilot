# Objetivo
Construir copilots de IA estables, trazables y seguros para uso en produccion.

# Activar skills
- ai-agent-design
- backend-realtime

# Reglas
- Definir contratos de entrada/salida antes de implementar.
- Minimizar alucinaciones con contexto y validaciones.
- Garantizar experiencia realtime consistente para el usuario.

# Flujo
1. Definir objetivo funcional del copilot.
2. Diseñar flujo del agente y limites de contexto.
3. Integrar canal realtime con manejo de reconexion.
4. Validar calidad, latencia y fallback.
5. Documentar limites y riesgos operativos.

# Output
- Blueprint tecnico del copilot.
- Reglas de contexto y seguridad.
- Checklist de operacion en produccion.
